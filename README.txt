OHIO STATE BUCKEYES FOOTBALL — WEBSITE PACKAGE
================================================

WHAT THIS IS
A responsive, professional-style single-page football website with working navigation, roster filters and search, clickable player-profile modals, a sample schedule, stats, news cards, recruiting buttons, and external redirects.

IMPORTANT TEAM IDENTITY NOTE
Ohio State Buckeyes is the correct team name. This is an unofficial fan-made website concept using scarlet-and-gray styling; it is not affiliated with or endorsed by The Ohio State University. Roster entries, opponents, schedule, and statistics are sample/demo content, not real or live data.

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open the ohio_state_buckeyes_site folder.
3. Double-click index.html to open it in a browser.
4. Navigation, player profiles, filters, search, and sample story buttons work locally. Google Fonts require an internet connection; the site still works without them using fallback fonts.

CUSTOMIZE CONTENT
- Roster, schedule and redirect configuration: script.js
- Team name, news cards, links and page content: index.html
- Colors, spacing and responsive design: styles.css
- Replace the placeholder recruiting and contact URLs in index.html before publishing.
- Replace demo player data and sample fixtures/stats with your own. The website does not fetch live stats or official rosters.

HOST ONLINE WITH GITHUB PAGES (FREE)
1. Sign in or create an account at https://github.com/.
2. Create a new public repository, for example ohio-state-buckeyes-site.
3. Upload index.html, styles.css, script.js, and README.txt from the extracted folder into the repository root (not inside another nested folder).
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish and copy the site URL shown in Settings → Pages. It usually resembles https://YOUR-USERNAME.github.io/REPOSITORY-NAME/.

EMBED IN GOOGLE SITES
1. Publish the site online first using the steps above. A local file path will not work for visitors.
2. Open your Google Site in edit mode.
3. Choose Insert → Embed → By URL.
4. Paste the published GitHub Pages URL and select Insert.
5. Resize the embed frame to fit the page and publish the Google Site.

NOTE ABOUT GOOGLE SITES
Google Sites embeds the hosted website; it does not convert the ZIP into native Google Sites sections. Your custom site's buttons work within the embedded website. External redirects open their configured destinations. If a website refuses to load inside an embed, visitors can use its direct published URL instead.
